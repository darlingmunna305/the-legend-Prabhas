## 🌐 DEPLOY TO VERCEL - STEP BY STEP

### Option 1: Deploy Without Code (Recommended for First Time)

1. **Push to GitHub**
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/prabhas-website.git
   git branch -M main
   git push -u origin main
   ```
   (Replace YOUR_USERNAME with your actual GitHub username)

2. **Go to Vercel.com**
   - Sign up with GitHub
   - Click "Add New" → "Project"
   - Select "prabhas-website" repository
   - Click "Import"

3. **Add Environment Variables**
   - Click on "Environment Variables"
   - Add variable:
     * Name: `VITE_RAZORPAY_KEY_ID`
     * Value: `rzp_test_xxxxxxxxxxxx` (your key)

4. **Deploy**
   - Click "Deploy"
   - Wait 2-3 minutes for build
   - Get your live URL! 🎉

### Option 2: Deploy via Vercel CLI

```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel

# Follow prompts:
# - Link to account? Yes
# - Which scope? Select your account
# - Link to existing project? No
# - Project name? prabhas-website
# - In which directory? ./
# - Overwrite settings? No
```

### Option 3: Deploy from Command Line

```bash
# Build locally first
npm run build

# Deploy the dist folder
vercel --prod
```

## 🐛 TROUBLESHOOTING

**Build fails?**
- Run `npm install` again
- Delete `node_modules` and reinstall
- Check Node version: `node --version` (need 18+)

**Images not loading?**
- Check Vercel Build Logs
- Image URLs might be blocked
- Run `npm run build` locally to test

**Payment not working?**
- Verify Razorpay key in environment variables
- Check browser console for errors (F12)
- Test with Razorpay test credentials first

**Site is slow?**
- Check Vercel Analytics
- Optimize images
- Monitor database queries
